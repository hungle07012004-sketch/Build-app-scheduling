# Industrial factory assets

Created 9 November 2026 using the built-in imagegen tool and the three factory photographs supplied by the user as visual references. These are AI-generated adaptations, not byte-for-byte copies of the uploaded originals and not evidence of an actual AL13 factory installation.

- `factory-hero.webp`: Dashboard hero; orange robot/conveyor at right, dark negative space at left.
- `factory-panorama.webp`: Sidebar lower background; panoramic assembly line fading into navy.
- `factory-studio.webp`: Workspace and sign-in background; wide factory floor and robot at right.

All assets are standalone factory imagery with no UI, text or watermarks. The generated PNGs remain in the Codex generated-images directory. WebP encoding preserves dimensions and composition; quality 0.86, no additional crop or scene edit. CSS controls the presentation crop and gradients.

Prompt set: photorealistic modern automated assembly hall, orange industrial robots, steel conveyors and overhead gantries, cool navy lighting with warm orange highlights, dark left/bottom space for HTML content; landscape 16:9; no typography, UI, logos, watermark or collage. Each generation used the corresponding user photo composition as described above.
